# 绮梦庄园 · 0.9 牧场秩序样板

工作名称。面向微信小游戏的原创角色外观与幻想农牧场项目。

## 最新交付（0.9）

- 水槽、饲料槽增加独占使用位置和等待处理，避免羊群全部争抢同一点。
- 购羊性别调整为公5%、母95%，独立随机；受孕概率仍为65%。
- 每次交配结束后公羊休息10分钟，不论受孕成功或失败；休息倒计时保存，正常照料和出售不受影响。
- 保留现有性别、成长与配对数据；新规则和验证见 `docs/ranch-v09.md`。

## 已有羊群成长（0.8）

- 羊本身可养大出售：幼羊60金币，有水有料累计120秒成熟，成羊90金币；同性羊同样可成长获利。
- 每只羊有成长进度与出售按钮，支持关闭自动配对，参与繁殖的父母暂时锁定出售。
- 羊群自主走动、趴卧、低头吃草，到槽边吃料和饮水；成长时体型逐渐变大。
- 旧版已有羊按成熟羊保留，旧孕育和库存继续有效。当前数值是试玩配置。
- 规则与验证见 `docs/sheep-growth-v08.md`。

## 已有牧场功能（0.7）

- 单只羊即可加水、添料；水槽和饲料槽有可见余量，可点击槽体操作。
- 每只60金币，公母独立随机各50%，最多6只；可转让空闲种羊返30金币。
- 公母与水料齐备自动配对，交配30秒、65%受孕，成功后孕育90秒；失败后可自动重试，不自动扣金币。
- 照料仍可加速孕育一次；旧种羊迁移为一只母羊，保留旧幼崽、库存和钱包。
- 当前试玩规则和验证见 `docs/ranch-v07.md`；此规则替代旧的单只羊付费繁殖。

## 已有成长功能（0.6）

- 作物和牧场显示成长进度与成熟倒计时，按实际经过时间自动成熟。
- 每批可浇水/饮水一次（免费减 20% 基础时长），施肥/营养饲料一次（花费金币减 30%）。
- 照料状态随存档保留，成熟后停止收费；场景显示水滴或营养粒子。
- 快速试玩数值、限制与测试见 `docs/growth-care.md`。

## 已有美术样板（0.5）

- 新美术基准：约三头身角色、宽圆脸型、清晰发块、小巧身体；三个服装轮廓和动作支点同步适配。
- 奶油小屋、圆角田框与花箱、鼠尾草绿屋顶、柔和统一灯光。
- 取消细密刺绣与写实木纹，采用纯色风格化 PBR 材质。
- 旧存档与五官参数兼容，但新比例下外观会变化。旧概念图不再作为比例标准，详见 `art/reference-lock.md`。
- 仍是可运行美术样板，非正式精修模型、非微信上线包。

## 历史交付（0.4，纹理方向已被新风格替代）

- 原创运行时绘制材质：裙摆花枝刺绣、滚边、织物微表面、木纹与土壤颗粒。
- 木屋窗台花箱与门前盆栽，奶油纸色、鼠尾草绿和金色点缀界面。
- 修正常服内外裙摆交叠；保留三套服装切换与关节步态。
- 材质生成代码随单文件打包，不需要远程图片。角色拓扑、头发和面部仍待精修。

## 已有经营功能（0.3）

- 牧场经营：购买绵羊种畜、投喂、计时生产、收获入库、单独出售；保留种畜进入下一轮。
- 幼崽偷取：所有访客累计最多半批，每人每批一次；偷来幼崽仅出售，访客库存和金币与主人分开。
- 衣橱：田园常服、分层礼裙、游侠长衣三种程序生成轮廓；仍非正式精修服装。
- 兼容：自动迁移 0.2 存档并保留一次备份；新 QM3D2 分享码包含服装轮廓，旧 QM3D1 仍可导入。
- 仍使用固定体验等级 8。天马与麒麟仅展示锁定门槛，尚未开放生产。

- **可编辑角色源文件**：`art/source/character-prototype.blend`，由 `scripts/build-character.py` 重建。

## 运行

Node.js 22 或更新版本。依赖版本已锁定：Three.js 0.180.0、esbuild 0.25.12。

```sh
cd /workspace/wechatgame
npm ci --cache /tmp/qimeng-npm-cache
npm run build:play
npm start
```

开发服务器监听本机端口 4173，三维主页 `/`，开发源码入口 `/play.html`，美术方向页 `/art.html`，角色建模参考页 `/character-sheet.html`。原型使用浏览器本地存储，访客及时间推进均为演示。不要把本地计时和金币数据用于正式上线经济。

```sh
npm test
```

浏览器验证另外使用当前环境已有的 Python Playwright 和 Chromium；它们不是 Node 项目依赖。旧版验证见 `scripts/browser-smoke.py`；三维验证见 `scripts/browser-3d-smoke.py`（默认测试端口 4174，可用 QIMENG_TEST_URL 修改）。0.2 记录见 `docs/validation-3d.md`；0.3 新测试为 `scripts/browser-ranch-smoke.py`，记录见 `docs/validation-v03.md`。
