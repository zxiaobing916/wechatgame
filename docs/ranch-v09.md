# 0.9 槽边占位与公羊休息

## 试玩数值

- 新购买：公羊5%、母羊95%，每次独立随机，没有保底；不会重新抽取已有羊的性别。
- 受孕概率保持65%，与购羊性别概率是两套独立规则。
- 每次交配完成后，参加的公羊休息600秒。受孕成功或失败均触发，下一次配对必须等休息结束。
- 冷却以交配结束时间为起点；离线经过的时间正常计入。刷新、收获、补水补料不能清除冷却。
- 冷却期间可以吃喝、移动和出售；仍在孕育中的父母维持原来的出售保护。
- 如果有其他成熟且不在冷却中的公羊，则在整栏没有活动配对或幼崽批次时可以选择它。

## 槽边行为

每个槽有独立占位，来访羊不能直接争抢同一个坐标。占位随行为结束、羊离开/出售、槽变空而释放。等待与移动同样需要保持间距，不能仅靠将重叠的羊慢慢推开。

仍为轻量程序行为和碰撞避让，不等于完整物理模拟或导航网格系统。验证应包含多羊同时趋向一个槽，而不只检查单只羊能到达。

## 存档

牧场状态升级至version4。保留旧羊性别、成长、食水、配对结果与库存，旧羊缺失的冷却字段补为0；旧的进行中交配结束后也应用冷却。原文备份到 `qimeng-3d-v1-before-ranch-v4`。

- 28项规则测试通过，覆盖性别边界、成功与失败冷却、离线时间及旧存档迁移。
- 浏览器经营回归通过；三羊争用水槽、饲料槽分别连续300模拟秒，均依序获得服务，体中心间距至少0.784。
- 最终单文件HTML在阻断外部资源请求的浏览器测试中完成模型加载、购羊、补水补料和活动文字显示，无JavaScript异常。当前测试浏览器策略禁止直接file导航，因此该项使用内存响应加载同一HTML。
