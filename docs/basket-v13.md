# 0.13 寻找月绒羊

## 定位

庄园仍为经营与收藏展示主玩法。辅助玩法采用原创立体找物、三件同类打包，暂不制作二合一。第一版为一个固定关卡，目标是通关直接领养一只月绒羊，不额外抽取概率。

## 规则

编织浅篮里有花朵、梨、线团、贝壳、莓果、叶片6类物件，各6件，共36件。12处叠放位置，每处3层，移开上层后才能选择下层。物件是关卡道具，不来自玩家材料仓。

点击放入7格托盘，同类累计3件立即打包移除；匹配先于满盘失败判定。清空全部物件获胜，托盘7格未能凑成三件则失败。拖动或按钮可旋转篮子观察；提供可拿取物件辅助列表。

没有倒计时，不扣金币/材料，不限重试。重试重置当前棋盘并保留相同布局；已成功的领养资格始终保留。已通关后可以练习，不重复发放羊。当前进度、失败/成功、尝试次数和领取状态均保存。

## 奖励与后续养成

首通获得唯一月绒羊领养资格，点击带回牧场。围栏6只已满时暂停领取，不丢奖励；腾出位置后可领取。奖励为固定母幼羊，不消耗玩家金币。

自然成长8小时，原有饮水、饲料及间隔加速规则照常。成熟后每4小时可梳理2份月光绒，计入每日梳理任务，用于制作月羽礼服。月绒羊有独立奶油/淡紫外观和金色月牙饰记，照料或天气变异不覆盖其身份。作为唯一收藏伙伴不可出售或提前转让，普通羊规则不变。繁殖不复制收藏身份，子代仍按原商品幼崽规则。

## 表现与范围

六类程序化立体物件、统一光照阴影、浅篮编织结构；顶层提示不透露隐藏层的可用性。射线不穿透前方物件。寻宝与庄园两个渲染器仅活动场景渲染，减少双画布开销。月绒羊奖励预览来自同一游戏模型，离线包内嵌预览图和模型。

这是单关原型，尚未通过真人测试校准通关率，不能承诺玩家尝试2至5次就能通过。关卡没有后台放水或强制失败逻辑。正式联机领奖与防篡改仍需服务端。

## 验证

62项规则测试通过，包含可解路径、实际失败、重试固定布局、三件优先消除、非法拿取、领取幂等、满栏保留、月光绒冷却与收藏保护。渲染测试覆盖12个初始物件真实鼠标拿取、拖动不误点、场景暂停、手机画面范围。

浏览器完整流程通过：实际拿取失败→刷新保留→固定重试→合法通关→免费唯一领养→成年梳理月光绒→收藏保护，手机无横向溢出。单文件包在外部资源阻断时加载两套3D场景、奖励预览并完成真实鼠标拿取。
