# 0.2 三维集成验证

日期：2026-10-16。Node.js 24.19.0、Blender 4.3.2、Three.js 0.180.0、Linux Chromium + Playwright。

## 实际交付

- Blender 源工程、可复现建模脚本与导出的 keeper.glb。50 个网格、62 个节点，约 2.5 MiB。
- 真正的三维农田、房屋、树木、简化羊圈与角色，可改变镜头和角色位置。
- 角色八项外观参数、眼型预设、同套服装三种配色、版本化分享码和本地存档。
- 固定等级 8 的本地经营演示。六块田，玉米／西瓜，成熟、收获自动出售及访客偷取。
- play-offline.html 和主页包含渲染代码、样式和 GLB，约 3.89 MiB；无需额外模型或图片请求。浏览器仍需允许脚本与 WebGL。
- 概念图角色的正侧背设计参考，已内嵌到 character-sheet.html。它是生成的建模参考，并非精确测量的正交图；视图细节需后续统一。

## 验证通过

`npm test`：7 项领域测试通过。

`npm run build:play`：打包成功。

`python3 scripts/browser-3d-smoke.py`（开发服务器端口 4174）：

1. GLB 实际加载成功，WebGL 输出三角形，不是替代模型回退。
2. 更换眼型实际改变 EyeL 节点缩放；脸宽数值 35 对应实际 morph 权重 0.7。
3. 生成／导入分享码成功，越界参数被拒绝；刷新后外观、衣服配色与金币保留。
4. 西瓜播种扣 12 金币，未成熟禁止偷取；五位访客各取 4，累计 20 后第六位无法再取；重复访客被拒绝。
5. 主人收获剩余 20 并出售；金币从 200 → 188 → 208。
6. 键盘移动改变实际角色位置。
7. 390px 手机布局无横向溢出，农场和捏脸页面截图已检查。
8. 将内嵌 HTML 载入禁止 HTTP/HTTPS 请求的页面后，模型仍加载并可调整眼型。
9. 上述流程无浏览器脚本异常。

截图位于忽略目录 `.artifacts/3d-*.png`。当前测试是桌面 Chromium 的不同视口，不是微信真机或手机性能测试。

## 尚未达到的正式制作标准

- 技术角色是原创简化程序建模，精细度、身份特征、发丝、皮肤、刺绣和材质尚未达到已确认概念图。正式角色必须按 `art/reference-lock.md` 继续制作，不能把此模型视为已验收的成品。
- 暂无真实骨骼行走、表情、布料、角色碰撞与导航。行走只是位置变化和轻微起伏；羊为程序几何示意。
- 当前换装是配色，不是不同版型服装切换。八项捏脸参数不代表完整专业捏脸系统。
- 牧场生产、等级成长、完整物品背包和经营平衡未实现。
- 没有微信构建、身份、好友、云存档、原子服务端经济或防作弊。
- 未在用户侧预览面板验证；内嵌资源解决路径依赖，不能保证平台会允许 WebGL 或脚本执行。
