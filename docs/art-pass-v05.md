# 0.5 轻3D奶油田园样板

用户新标准：Q版、清爽、奶油田园、柔和统一光照、干净轮廓，替代早期成人比例和密集纹理。具体标准见 `art/reference-lock.md`。

## 实际资产变更

- Blender 重新生成角色 GLB 与可编辑源文件：约三头身、较宽圆脸、大眼、小嘴、成块头发、小巧身体；移除细密刺绣和碎发。
- 新建模脚本仍保留 Face/FaceWidth、EyeL/R、BrowL/R、Nose、Mouth 参数接口。旧参数可以加载，但形象不与旧模型完全一致。
- 三套服装与运动支点按新比例适配；捏脸近景相机重新定位。
- 统一粗糙度较高的纯色 PBR 材质，取消运行时噪点、木纹和花纹贴图。
- 小屋新增闭合山墙、圆形阁楼窗、宽窗框、花箱和台阶；田框及水槽圆角处理，降低背景花草密度。
- 主光方向固定，奶油环境补光；没有把精细烘焙或布料模拟声称为已完成。

## 边界

这是可运行的美术方向样板，不是最终精修角色。仍缺少蒙皮、表情与布料碰撞；移动采用刚性关节动画。真实微信运行时、设备帧率/内存和服务端好友尚待验证。场景约 8 万三角形、近 300 绘制调用，正式手机版本还需合批、实例化与真机预算验证。

单文件产物约 1.85 MiB，包含代码和模型，不依赖外部纹理请求。旧概念图页面已标明历史参考。

验证：13 项领域测试通过；三套服装动作/复位及捏脸通过；三维浏览器回归通过（GLB、形变、分享码、存档、农场、移动、手机视口、完全拦截网络后的内嵌加载）。最终微调头部高度后重新构建并检查角色和农场截图，无脚本错误。
