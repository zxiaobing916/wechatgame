# 0.3 验证记录

日期：2026-10-16。环境：Node.js 24、Python Playwright、系统 Chromium，软件 WebGL；不是微信真机性能测试。

## 已通过

- `npm test`：13 项领域测试通过，覆盖成熟边界、共享半产量上限、奇数产量保底、重复访客、种畜保留、出售限制、独立钱包与异常数据。
- `npm run build:play`：生成约 3.91 MiB 的单文件页面，内含 Three.js、界面、规则和 GLB。
- `python3 scripts/browser-3d-smoke.py`：真实 GLB 加载、眼部节点与脸宽形变、分享码校验、持久化、农场共享偷取与收获、角色移动和手机布局均通过；拦截全部 HTTP/HTTPS 请求后，内嵌页面仍能加载模型和操作捏脸，无脚本错误。
- `python3 scripts/browser-ranch-smoke.py`：旧存档迁移及备份、购买和投喂、成熟幼崽、共享偷取上限、双方分别出售、第二轮繁殖、旧农田收获、新旧分享码、刷新恢复均通过，无脚本错误。
- 桌面与 390px 手机视口：牧场和衣橱无横向溢出。视口检查不代表真机适配完成。
- 实际查看修复后礼裙及游侠服截图：修正裙层、内衬、裤腰、靴子重叠，以及领口连接。服装仍为简单程序几何，不是精修成品。

## 0.3.1 动作增量

角色新增 10 个刚性关节支点，覆盖原角色双臂与双腿、两套附加服装袖口、游侠裤腿和靴子。行走驱动摆动，停止时平滑衰减；切换捏脸、衣橱或牧场会重置姿态。保留原有五官节点、脸宽形变及服装显示逻辑。

这是运行时刚性层级动画，尚不是带权重蒙皮的正式骨骼动画；长裙和披肩不随步态变形，未实现足部贴地或布料碰撞。新增浏览器检查：`python3 scripts/browser-motion-smoke.py`。

本轮验证：13 项领域测试通过；新增浏览器动作检查通过（10 个支点、三套服装摆动、角度有效、切换姿态复位和捏脸操作），无脚本错误。已实际查看游侠服复位截图；内嵌构建成功。未进行微信真机测试。
