# 0.21 散落篮子与轻晃观察

篮子内保留 108 件、9 类物品与七格托盘，改用随机横斜朝向及不规则支撑位置。用保守包围球生成无相交的初始摆放，以覆盖关系决定能否拿取。每天布局固定，有一条无需复活的完整解法。

拖动可以小幅改变视角并倾斜篮子，松手回稳；“轻晃”按钮触发短暂摆动。动作不消耗次数、不重洗物品，也不改动托盘或奖励。当前是整体倾斜观察，物品尚不具备各自滚动、掉落和重新堆积的完整刚体模拟。

旧列状布局的存档迁移时重新开始当天散落挑战，保留累计通关、领取状态及未领取奖励。新布局存档正常续玩。每日奖励、免费重试、模拟广告复活仍沿用上一版规则。

验证：76 项领域测试；包含 30 天完整解法、摆放间距、存档迁移、复活和奖励守恒。浏览器检查手机尺寸下轻晃与拖动不误拿、真实触屏拾取和完整通关。固定贪心策略在十天布局共 100 次试验中成功 45 次；这不是人类胜率，不能据此宣称达到商业游戏高难关的难度，仍需玩家测试调优。
