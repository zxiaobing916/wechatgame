# 0.20 每日高难寻宝

入口直接进入每日高难挑战，不再提供简单前置关。108件、9种物件、12叠各9层，仍为三件同类消除、七格托盘。当天布局固定，免费无限重试；次数不影响布局或奖励，不随失败偷偷改变难度。

北京时间00:00切换日期。新一天重新开始挑战、换布局与奖励；正在进行的上一天挑战结束，已赢取的未领取奖励进入保留清单。离线跨过多天只生成回来当天的关卡，不补发没赢取的奖励。时钟倒退不会把当前日期回滚。本地原型使用设备时间，正式版需要服务端日期和领奖记录，当前不具备防改时钟能力。

奖励按日轮换：羊毛4、金盏染料3、月光绒1、蔷薇染料3、月绒羊。领取唯一伙伴时若已拥有则发月光绒2；牧场满且尚无伙伴时保留资格。开局不显示奖品名称，清空后揭晓。每个日期只获得一份奖励资格，重复通关不重复发。旧版未领取月绒羊资格迁移保留，旧版已拥有伙伴不受影响；旧版未完成棋盘转入新挑战。

复活：仅失败时可用，每局最多2次，回退最后3步，并把物品恢复到原叠层；不删除物品、不破坏三消配对。重新挑战重置本局复活次数。当前按钮明确标注“模拟广告”，弹窗可模拟观看完成或取消，取消不消耗次数。重复完成回调或跨天失效的请求不能继续发复活。尚未接入真实微信广告、广告位或服务端验证；正式接入需由广告完整观看回调与服务端状态共同控制，不能把关闭广告视为观看完成。

布局按日期种子生成，并保留经合法步骤构造的完整解法。难度来自更多层、干扰项、观察与记忆，所有关卡都能不靠广告解开。此版“高难”是配置定位，并未用真实玩家数据验证通关率，不宣称达到某款商业游戏第二关的相同难度。上线前需测无复活通关率、失败步数分布、复活后通关率和手机帧率，再调复杂度。

验证：30个不同日期的108步合法无广告解法；重试一致、取消与完整观看模拟、两次上限、刷新恢复、北京时间跨日、奖励幂等、旧资格迁移与唯一伙伴补偿。浏览器覆盖实际触屏拿取、完整通关、奖励入库及次日更新。执行 npm test 和 python scripts/browser-daily-basket-smoke.py。

难度试验：相同的简单贪心策略在100次自动尝试（10个日期）中，六类物件版本赢80次；增加宝石、纽扣、铃铛为九类后赢18次。该数值只用于比较两版配置，不代表玩家通关率，也不作为广告收益预测。现版本可运行 node scripts/analyze-daily-difficulty.mjs 复现后者。
