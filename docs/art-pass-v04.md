# 0.4 首轮材质与场景装饰

保留已确认的象牙白、鼠尾草绿、古金和淡紫配色。本轮把原创程序绘制纹理接入实时 Three.js 材质，而不是增加一张概念展示图。

## 已接入

- 512×512 织物凹凸纹理、花枝与金线裙摆纹理、木纹和土壤颗粒；固定种子，跨刷新生成一致。
- 常服重新生成圆柱 UV；礼裙采用既有旋转曲面 UV。服装配色仍可修改。
- 木屋、木栅栏和田框使用木纹，窗台增加小花，门前增加淡紫盆栽。
- UI 的纸色背景、细金线、选中卡片和标题装饰。
- 常服衬裙横向收进，避免与外裙交叠。

所有纹理在本地 Canvas 绘制后上传至 GPU，不请求外部图片；通过各向异性过滤改善斜视质量，卸载场景时释放纹理。使用的是实时技术模型，面部拓扑、发丝、手部和布料权重尚未精修。本轮没有声称达到概念图品质。

实际浏览器查看农场与三套服装，无脚本错误。截图保存在 `.artifacts/art-*-v04.png`。未进行微信真机性能测试；不以桌面视口结果代替手机 GPU 验证。
