# 0.14 便捷经营与篮底珍藏

## 移除抽奖

删除抽奖入口、抽奖领域接口、发券任务和保底机制。工坊存档升级至v2，仅保留材料、服装收藏与装备。原有材料和衣服完整保留，旧档未使用奖券按每张2份羊毛一次性补偿；重载不重复兑换。升级前原文备份到qimeng-3d-v1-before-atelier-v2。

服装继续由材料制作，月光绒可兑换或通过珍藏伙伴梳理获得。配方显示缺少的材料和来源按钮，可跳到农场选好对应种子、牧场查看梳理，或定位兑换按钮。

## 农场一键操作

- 播种：使用当前选中种子，按地块顺序只填空地，不替换已有作物。
- 收获：仅收当前已成熟、未收获的本人作物，按被偷后剩余产量和变异倍率计金币，每批发对应染料。
- 浇水：仅处理尚未成熟、尚未浇水的作物，免费，每批一次。
- 施肥：仅处理尚未成熟、尚未施肥的作物，按品种扣2或3金币，每批一次。

按钮显示可执行数量、费用或预计金币收入。金币不足时按地块顺序执行可支付前缀，不透支、不重复扣费。异常操作返回前不修改状态。单地块原有按钮保留。作物时间仍为原型演示值60/90秒，本次不调整正式经济周期。

## 牧场批量购买

目前仅开放绵羊。按6只围栏容量和每只60金币计算可买数量，显示数量和总价；每只性别独立抽取，已有动物不变，新买动物从幼年成长。牧场不增加一键浇水，原有按需求补给规则保留。

## 篮底珍藏揭晓

首次挑战前只给出牧场伙伴类别，不展示具体名字或预览。篮底加入独立的珍藏模型，初始覆盖，整理后逐渐露出，清空后睁眼、轻微呼吸并平滑靠近展示。珍藏不属于可消除物件、不占托盘、不改变固定36物件关卡，不添加篮子抖动。

通关后才显示名字、用途及领养按钮。奖励固定、领取资格存档、满栏可稍后领、只领一次；已经发现的玩家继续显示已知奖励，不重置既有收藏。

## 验证

70项领域测试通过，覆盖迁移补偿幂等、材料保存、批量混合地块/低余额/满栏/重复操作/错误回滚、原有变异和领奖保护。浏览器验证批量播种照料收获购买、余额与容量限制、旧档补偿只发一次、无抽奖入口、材料制作换装保存及手机布局。篮子渲染测试完成旋转手机视角36次真实点击并验证逐渐揭晓。

完整寻宝浏览器流程通过：失败/重试/通关/唯一领养/成年产绒。最终离线包在阻断外部资源时完成六地块播种、无抽奖入口与未通关隐藏奖励检查。
