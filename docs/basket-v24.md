# 0.24 手机摇晃入口与受限表层颠动

点击“开启摇一摇”后接入浏览器 DeviceMotionEvent；需要授权的浏览器在点击手势中申请权限。支持微信加速度计适配，统一 g 与 m/s² 单位。当前项目仍是网页原型，微信小游戏发布与真机传感器灵敏度尚未验收。

识别两个短时间内反向的加速度变化，过滤普通持机的小动作；触发间隔至少 1.4 秒，力度封顶。切出寻宝、打开编辑面板、游戏不在进行中或页面隐藏时忽略传感器输入。可点击关闭监听；不支持或拒绝权限时保留“轻颠”。浏览器可能要求 HTTPS，部分内置浏览器不提供运动事件。

每次最多选择五件没有近距离上方压盖的表层物件，小幅抬起（最多 0.2 场景单位）、转动（约 12 度以内）和落稳（0.8 秒）。落位允许受邻近约束的小幅累计挪动，上限固定，底层不被直接提起。不会重洗、拿取或修改奖励进度。

本次是受约束的表层动作与邻近检查，仍不是完整的刚体接触、摩擦与滚动求解；真机手感和更自然的接触运动需继续优化，不能视为《抓大鹅》物理效果的复刻。

验证结果：82 项测试通过；390×844 浏览器中用受控时间戳注入模拟运动事件，验证运动授权入口、触发颠动、最多五件物体参与、不误拾取、关闭监听和按钮触发。未完成真实手机或微信小游戏真机测试。
