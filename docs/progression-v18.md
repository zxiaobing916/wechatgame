# 0.18 九格田园与寻宝图形托盘

新档：1级、40金币、九格田中仅第一块可用。玉米1级开放，每批收获出售增加10经验；西瓜3级开放，每批增加16经验。浇水、施肥、偷取、仅播种和重复收获不授予经验。一键收获逐批结算经验。

先解锁前一块，再检查等级和余额。升级不会自动开田；解锁只扣一次钱。锁定地不播种、不参加批量照料。第一批玉米收获后从40→32→62金币并升2级，开第二田后余42金币，足够继续播种。此版仍使用原型的60/90秒作物时长，费用和经验为待试玩调优的初稿；当前等级上限9级。

旧6田存档迁移为8级、500经验，原6田全部保留为已解锁，追加3块锁定田；金币、作物、服装、羊和寻宝进度不重置。正常新档只开1田，旧档再次读取不会再次迁移。

寻宝视野放大约13%，不改变关卡排列、物品数量或遮挡规则。六类物件的托盘缩略图直接复用篮内模型生成，名称通过无障碍标签和悬停提示保留。三件消除与七格容量不变。

验证：68项领域测试通过；浏览器用实际触屏验证收获升级、顺序付费开田、刷新保留、托盘模型图像加载与360/430宽度适配。
