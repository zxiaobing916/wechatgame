# 0.22 大物件堆积与倒计时

物件尺寸由 0.84–0.98 提升至 1.6–1.8，花瓣、贝壳和叶片增加厚度。篮内保留 108 件、9 类，采用随机姿态和多层紧密遮挡，近俯视镜头保证堆积落在画面内。

点到实际露出的模型表面即可拿取，不再要求下层物件的所有覆盖者先移除。射线只取最近的可见表面，不能穿过上层拿取。辅助操作列表仍只列无覆盖者物品。

移除后按包围球支撑关系施加重力，仍在上方的物件下落补位；轻晃带来有边界的小幅独立位移与支撑调整。当前为简化的球体碰撞及垂直落位，不是精确网格刚体滚动。摆动不洗牌，初始布局与免费重试仍按日期固定。

每局十分钟，存储绝对截止时间，离开页面仍计时；超时停止拾取，可免费重试。每局最多两次模拟广告复活，每次增加两分钟，托盘满时另退回三步；超时复活不退回拾取。真实微信广告尚未接入。计时为本地原型，上线需服务端校验。

旧布局升级会重新开始当前挑战，保留已得奖励及领取记录。当前布局正常保存继续。

验证结果：78 项领域测试通过；390×844 触屏浏览器完成轻晃/拖动不误拿、真实射线拾取、完整通关、十分钟超时及复活恢复至两分钟的检查，未捕获页面脚本异常。
