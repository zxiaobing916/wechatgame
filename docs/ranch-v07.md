# 0.7 牧场生活与概率繁殖

## 当前试玩规则

- 每只绵羊60金币，公母独立随机各50%，允许连续同性。最多6只；空闲种羊可转让返还30金币，避免全同性满栏后无法调整。
- 一只羊即可日常照料，无需配对、无需先付8金币。点击实际水槽或饲料槽，也可使用面板按钮。
- 两槽容量均4份。添水免费，添满饲料3金币；满槽且没有可用孕育加速时禁止重复收费。
- 每60秒全栏消耗水与饲料各1份，离线按经过时间扣至0；不会导致动物死亡或取消已开始的孕育。
- 同时仅处理一对公母。两性俱全、两槽均有余量、没有待收幼崽或正在进行的配对时自动开始；配对额外消耗水料各1份，不自动扣金币。
- 交配期30秒，受孕概率暂定65%；结果在配对开始时抽取并保存在本地存档，刷新不会改变。成功后孕育90秒并产4只幼崽；失败后水料足够会重新经过完整交配期，不保证成功。
- 孕育期间饮水和营养饲料每批仍各可加速一次，分别18/27秒。满槽也可做尚未使用的加速，饲料只扣一次3金币。
- 幼崽偷取共享最多一半、仅能出售、主人与访客钱包独立；成年羊不会被偷。待收幼崽收获后才开始下次配对。
- 交配或孕育期间不允许转让种羊。转让最后一只后保留仓库和资产。

## 存档与兼容

旧存档的一只无性别种羊固定登记为母羊，不重复抽签；已有孕育批次、库存、金币和访客收益原样保留，即便旧批次来自单只羊。旧存档原文备份到 `qimeng-3d-v1-before-ranch-v2`。新规则只约束后续配对。

离线只结算已存储的配对结果，不连续生成多批幼崽。库存吃喝扣至0后等待补给。当前仍是本地试玩；正式版需把随机结果、时间和经济转移到服务端，不能依赖客户端防作弊。

## 验证入口

`npm test` 覆盖单羊照料、公母抽样边界、同性无配对、容量与转让、概率成功失败、刷新稳定性、加速收费、偷取保护、迁移与非法数据。

`scripts/browser-ranch-smoke.py` 覆盖新牧场完整流程；`scripts/browser-care-smoke.py` 覆盖农场照料、独立单羊照料和离线内嵌。脚本通过注入时间和随机输入检查分支，不以等待真实分钟替代边界测试。

三维场景按成年羊数组显示数量和公母项圈，水料余量可见。当前反馈是粒子与槽体变化，尚非角色拿壶或动物进食的完整骨骼动画。

验证结果：17项领域测试通过；两个浏览器流程通过（单羊照料、同性购买、公母自动配对、成功/失败、刷新概率稳定、孕育加速、偷取上限、旧存档迁移、农场照料和离线内嵌）。三维槽体实际点击回调测试通过，已查看6只成年羊与4只幼崽同时显示的截图。未进行微信真机性能测试。
