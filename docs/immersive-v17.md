# 0.17 全屏触控
场景铺满手机画幅。默认经营界面没有常驻说明面板，保留金币、五个功能入口、帮助和短操作按钮。详细操作通过点选或主按钮展开，可关闭。寻宝的七格托盘属于玩法界面，悬浮显示。

触控：点田地打开操作，点空地行走，单指拖动旋转，双指缩放。拖动后回到原位置、双指接触均不触发单击。捏脸与衣橱进入后先展示人物，点击主按钮再编辑。现有移动仍为直线行走，尚未增加完整寻路避障。

验证：65 项领域测试通过；浏览器触屏验证包括实际射线点田、播种、人物行走、拖动与双指误触防护、购买羊、寻宝实际点选，以及五个模式切换。360×740、390×844、430×932 手机画幅和桌面手机框已检查。默认经营界面常驻 HUD 的矩形面积合计低于画幅 10%；弹出面板、提示和寻宝托盘不属于此默认状态。场景画布为 100% 画幅。

测试入口为 scripts/browser-immersive-smoke.py；browser-portrait-smoke.py 转接同一套用例。截图 web/assets/immersive-*.png 来自当前构建的实际运行，不是概念图。本版尚未进行微信真机验收。
