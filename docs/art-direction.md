# 绮梦庄园：美术方向与资产制作规范

> 这是制作规范，不是已交付的正式美术资源清单。程序几何体、色块和示意头像只能证明流程，不能代表最终服装、角色或农牧场质量。

## 1. 统一风格

精致、柔和、有生活气息的幻想田园。人物采用偏动漫比例、材质克制的风格化 3D；环境以温暖木材、清爽植被、柔和日光构成。由普通田园逐步出现月光花、天马与麒麟，幻想内容不应让整个画面充满高亮光效。

基础色板：奶油白 `#F5EEE2`、鼠尾草绿 `#8C9D83`、浅木色 `#B99572`、雾蓝 `#91ABB9`、淡紫 `#B3A1BF`、香槟金 `#C8AA70`、深墨绿文字 `#30463E`。色值为初稿，必须以实际对比度和不同屏幕验证；稀有度、成熟状态不能仅靠颜色表达。

不要把“精美”理解为堆描金、花边和粒子。优先轮廓、比例、材质区别、清晰层次及有节奏的留白。

## 2. 人物、头模与捏脸

- 头模采用统一拓扑、UV 与骨架约定，提前规划眼睑、嘴角、鼻翼及下颌变形环线。
- 眼球、上下牙齿、舌头与睫毛分件，处理闭眼、微笑与张口时的接触和遮挡。
- 捏脸形变与表情形变分开管理；极端组合需修正形态，不能只验证每个滑杆单独拉满。
- 头部与颈部接缝、法线、肤色必须连续。肩颈比例调整须与服装适配范围一致。
- 眉毛、妆容与眼线随面部正确变形；避免眉毛浮在皮肤上或眼线被拉裂。
- 不同肤色下检查阴影、唇色和高光；禁止只针对最浅肤色调材质。

第一批目标脸：圆润短脸、修长清冷脸、较宽下颌、柔和饱满脸、动漫大眼脸。每组验证正面、侧面、四分之三视角，以及眨眼、微笑与张口。目标是有区分且好看，不承诺复制现有 IP 角色。

## 3. 服装与配饰

先制作田园、幻想礼服、侠客服饰三个方向的概念设计，运行样板至少落地一套日常与一套复杂衣服。

| 方向 | 轮廓与材质 | 实机重点 |
| --- | --- | --- |
| 田园 | 刺绣衬衫、背带裙／长裤、短靴；棉麻与皮革 | 日常动作、近看有细节、远看轮廓清楚 |
| 幻想礼服 | 层叠裙摆、轻纱、珠饰与头饰 | 透明排序、裙摆运动、手臂穿插 |
| 侠客 | 交叠衣襟、腰封、护腕、长靴 | 修长比例、衣摆与腿部运动、金属与布料区分 |

制作前固定人体骨架、绑定姿势、比例、单位和服装槽位。定义上装／下装／连体装互斥，定义内外层优先级；穿上衣服时按区域隐藏身体网格，不能用整个人体隐藏代替所有遮挡规则。

长发、长裙和挂饰采用受控骨骼动画或经过预算验证的轻量模拟，不默认全身实时布料。跑动、转向、弯腰采摘和坐姿均需检查穿模。跨体型衣物必须单独适配或提供修正形态，不能承诺所有衣服无成本通用。

发型验证最大支持头宽、额头高度与耳位；耳饰和头饰跟随正确锚点。衣服美术设计不能依赖大量微小花纹才能辨认。

## 4. 农牧场

土地分为未开垦、已翻整、已播种、生长、成熟；状态同时使用轮廓、植株大小和适度提示。土壤有块面与色差，但不制作密集噪点。田埂、石径、草地自然衔接，成熟作物不能遮挡相邻格的点击判断。

普通作物先做玉米和西瓜：玉米突出直立叶片与穗，西瓜突出蔓叶和成熟果实。幻想植物先做月光花：白天也有清晰花形，夜光只是补充。每个物种至少有能读懂的生长阶段，而不是只缩放同一模型。

普通动物建立呼吸、转头、进食与行走；幼崽与成年体型有区别但保持物种辨识。天马的翅膀结构与收翼动作、麒麟的角与鬃毛需要独立设计，不能只对普通马换色。幼崽收获表达应温和清楚，避免把伙伴情感与交易文案混为一谈。

## 5. UI 与镜头

UI 使用柔和卡片、少量细线与克制的植物装饰，正文保持高对比。关键按钮明确标注“播种”“收获”“出售”等，装饰性命名不替代动作文字。经营 HUD 不遮挡角色脚下与田地；窄屏下主要操作可单手触达。

捏脸页：左侧或上方为角色预览，下方／侧边为部位分类、预设缩略图与滑杆；明确显示当前数值、恢复按钮和保存状态。切换预设若会重置局部微调，必须预览或可撤销。

镜头分经营、角色近景、拍照三种需求。近景使用中性灯光帮助判断五官，经营镜头优先点击可读性；拍照隐藏 HUD，不改变真实拥有物品。

## 6. 资产管线与移动端约束

源文件与导出资源分开存储，命名含品类、资产 ID 和版本。保留制作来源、作者、商用授权与修改权限记录；原创概念或工具生成图不是自动完成的可用 3D 资产。

角色、服装和场景制定独立预算，先在目标手机测量再固化面数、骨骼数、材质数及贴图尺寸。共享材质、纹理图集、LOD 与实例化按实测使用。透明材质、实时阴影、粒子和后处理要单独计量，不以桌面浏览器表现代替微信真机验收。

头像缩略图、物品图标与真实模型保持一致；避免概念图明显优于实机资产却用作实际效果宣传。

## 7. 美术样板验收清单

- 同一角色在捏脸页、换装页和庄园中外观一致。
- 两套服装在正面、侧面、背面和采摘动作下无明显身体穿插。
- 五组目标脸均能实现有效差异，眨眼闭合、唇部动作正常。
- 土地与作物生长状态在正常经营镜头下可分辨。
- 动物有基本生命感，成熟幼崽与不可偷种畜标识清楚。
- UI 在窄屏无关键遮挡，文字不依赖花体，可交互对象有足够点击区域。
- 完成目标设备性能记录；性能不足时优先调整资源与效果，不牺牲核心操作反馈。
- 评审材料同时提供概念图、真实运行截图、近景和普通经营视角，明确每种素材的性质。

下一步所需正式制作资产：带捏脸形变的头模与基础人体、眉眼睫毛和妆容资源、已绑定服装与发型、动作、分阶段作物、动物及幼崽、庄园模块与 UI 图标。当前文档不宣称这些资产已经完成。
