# 0.11 天气与变异

## 天气

每30分钟一个天气时段：晴天55%、雨25%、雪15%、雷雨5%。天气种子与已结算时段保存到本机存档，按种子及时间段确定天气，刷新不会换天气。雨、雪使用160个粒子的轻量效果；雷雨调暗光照并增加雨势，不使用频闪。

成长中的作物、幼羊、未成熟的幼崽批次在新雨/雪时段各有0.5%变异机会，雷雨0.3%，晴天没有。只在新时段开始判定一次，不按帧重复。离线最多补算最近48段（24小时），已成熟的对象不补抽。已有存档首次进入不回溯补抽未记录的天气。

## 照料

有效浇水、施肥、饮水、进食各有1%变异机会。原有照料次数和3小时需求间隔仍生效，重复点击不能额外抽取。仅对操作前未成熟的普通对象判定；若本次加速刚好成熟，仍可变异。成熟动物仍可被照料，但不再抽变异。

|形态|来源|售价倍率|
|---|---|---|
|露华|水、雨|1.5|
|丰盈|肥、饲料|1.5|
|霜晶|雪|2|
|雷光|雷雨|2.5|

只保留第一种变异，不叠加、不替换，不遗传给后代。变异不改变产量或累计最多偷取一半的规则。收获及被偷的商品保留变异；成熟羊按倍率出售，提前转让幼羊仍返30金币。各交易总价乘倍率后向下取整。

## 界面与保存

天气栏显示当前天气及更新倒计时，并列出作物和动物的变异名称。变异对象独立配色及宝石标识，不染色其他对象。出售按钮显示实际价格。现有存档保留，新增nature及可选mutation/weatherSlot字段。

此版本仍是本机浏览器原型，不能防止手工修改存档或系统时间。正式联网版本须由服务器产生并存储天气与随机结果。农作物仍使用60/90秒演示时长，因此只有成长期间跨越天气边界才参与天气判定；照料变异不受此限制。

## 验证

44项规则测试通过，覆盖概率边界、天气权重/结果稳定、离线补算、重复判定、成熟排除、倍率与偷取保护。浏览器测试验证四种天气真实画面、独立变异配色、作物与幼羊照料变异、重载存档、天气进度、溢价出售和手机布局。
