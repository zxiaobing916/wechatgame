# 0.8 羊本体成长、出售与生活动作

## 养成收入

新购羊为幼羊，每只60金币，性别随机。水与饲料同时有余量时累计成长，试玩设定为120秒成熟。同性羊同样可成熟；每只成羊可出售90金币，也可留下繁殖。界面逐只显示成长进度、缺食暂停提示与出售按钮。

缺水或缺饲料期间不增加成长；离线成长最多计算到剩余水料实际耗尽，补充后不会追补缺食时段。新购幼羊不会继承其他羊已经经历的成长时间。满120秒后封顶。

只有成熟公母可以配对。可关闭自动配对，专门经营养成出售；关闭不会取消已开始的交配或孕育。正在交配或孕育的父母暂时不能卖，其他羊可照常出售。旧版没有父母记录的孕育批次保守锁定整栏，收获后解锁。

未成熟羊仍可提前转让返30金币；产下和偷来的幼崽仍按旧规则只用于出售，不能转为种羊。

## 动物表现

- 羊有独立错开的行为节奏：走动、低头吃草、趴卧休息、到槽边进食/饮水。
- 走动有腿部摆动，吃喝有头部俯仰，休息有身体下沉。
- 活动限制在围栏内，并做基础距离避让；空槽不触发进食/饮水。
- 按动物ID保留模型和路径；每秒更新成长、补给或幼崽数量时不重置成年羊位置。
- 幼羊体型随成长逐渐变大。动画仅为视觉表现，经济消耗和成长由领域规则计算，不按帧扣费。

仍为程序驱动的轻量动画，不是精细骨骼蒙皮、复杂导航或完整动物行为模拟。

## 兼容与验证

牧场存档升级至version3。v0.7既有羊原本按成年种羊出售，因此全部登记为成熟羊，直接保留出售价值。金币、性别、配对结果、孕育批次和库存保留，原文另备份到 `qimeng-3d-v1-before-ranch-v3`。

规则测试：`npm test`；三只母羊养大出售：`scripts/browser-growth-smoke.py`；繁殖回归：`scripts/browser-ranch-smoke.py`；真实行为姿态、槽边吃喝和边界：`scripts/browser-sheep-behavior-smoke.py`。

所有时长/价格为试玩值，尚未进行微信真机性能、长期经济平衡或服务器权威验证。

验证结果：22项领域测试通过；三只母羊成长出售、缺食暂停、刷新保留、旧成熟羊迁移、新羊年龄独立、配对成功失败/偷取回归均通过。真实渲染器验证五种行为、姿态、范围、槽边吃喝和位置连续性通过。完全拦截HTTP/HTTPS的单文件页面也完成了买羊、喂水喂料、成长和出售。修复了每秒重建羊卡片导致出售按钮点击中断的问题，改为保留DOM节点更新内容。
