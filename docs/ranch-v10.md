# 0.10 牧场时光

幼羊自然成长8小时，离线计入成长，缺少水或饲料不会暂停成长。购买时即有饮食需求；每项照料仅对本次有需求的羊生效，水免费、一次添料3金币，每只幼羊各提前15分钟成熟，最多扣至剩余时间为0。

每只羊的饮水、进食分别设3小时需求间隔，错过的次数不累积。新购幼羊不重置其他羊的间隔。槽动画结束不能解锁照料，按钮根据需求计时启用。成年羊仍可照料但不再获得成长加速。

例：首次水和饲料照料后剩7小时30分；3小时后再次照料，剩4小时；第5小时回来仍剩2小时，照料尚未到期。若不再照料，第7小时成熟。完全不照料则第8小时自然成熟。

每个槽一次一只羊；在槽外排队、接近后低头，身体避让槽体。实际照料产生一次吃喝行为，槽中有余量不会触发无限循环。

公羊购买概率5%，每次交配后仍休息10分钟；成熟且饮食需求满足的公母才可开始配对。新孕育批次8小时，当前照料加速只用于幼羊成长，不加速孕育。已有孕育批次保留原到期时间。

存档升级v5，旧120秒成长进度按比例转换为8小时，保留成羊、金币、父母锁定与公羊休息时间。升级前原文备份到qimeng-3d-v1-before-ranch-v5。旧版饮食改为可照料状态。

仍为浏览器本地原型，现实时间以本机时钟计算；正式微信版本需要服务端时间与存档校验。农作物仍保留原演示时长，本次调整牧场。

## 验证

31项领域规则测试通过。浏览器用测试时钟验证三只母羊购买、首次照料、3小时边界、关闭重载后离线成长、成熟出售和390像素宽度布局。测试时钟仅存在测试脚本中。

渲染测试：幼羊与成羊分别争用水槽、饲料槽，各连续300模拟秒，三只均完成服务。检查模型身体与木槽壁不相交、嘴伸入槽内、头部高于槽沿，以及重复时间戳不重播。单文件包在阻断外部资源请求时完成模型加载与照料按钮验证。
