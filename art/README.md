## 转为真实资产前必须解决

1. 图中头发、透明纱、植被和细碎饰品细节密度高，手机实时版本需要减少透明叠层、烘焙材质并分级细节。
2. 女性角色示例不代表只支持女性；男性体型及各体型服装需独立设计与适配，不能宣称自动通用。
3. 角色头模必须有一致拓扑与可组合变形目标，测试眨眼、微笑、不同眼形和下颌组合。
4. 图中小天马与动植物需要正侧背设定、建模、绑定及动画；概念图不能代替这些工序。
5. 必须在经营镜头下验证成熟作物识别和点击目标大小；细节不能牺牲交互。
6. 当前未制作音乐、正式音效、商业服装模型或完整 3D 庄园。
