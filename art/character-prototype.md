# 原创 3D 角色技术样板

本资产由 `scripts/build-character.py` 原创程序建模，没有使用或提取《云裳羽衣》等商业游戏的模型、纹理或代码。视觉方向参考本项目概念图的奶油白上衣、鼠尾草绿长裙、棕色长发和金色细节。

**这是可交互技术样板，尚未达到已确认概念图的最终美术品质。** 不应称为概念图人物的完成版模型。头模拓扑、面部精细变形、头发、袖口、手部、服装裁剪、纹理、骨骼蒙皮和表情均需后续专业制作。

## 文件和复现

- `web/assets/models/keeper.glb`：运行时资产，glTF 2.0 / GLB，约 2 MB，无外部纹理依赖。
- `art/source/character-prototype.blend`：可编辑 Blender 源文件。
- `art/source/character-preview.png`：离线技术预览，不是最终概念图。
- 复现：在仓库根目录运行 `blender -b --python scripts/build-character.py`。
- 生成离线预览：`CHARACTER_PREVIEW=1 blender -b --python scripts/build-character.py`。
- 已用 Blender 4.3.2 验证。导出不需要 Draco。预览渲染使用 EEVEE。

## 坐标与参数接口

GLB 为 Y 向上、角色正面 +Z；脚底约 Y=0，头顶约 Y=1.74m，裙宽约 0.6m。默认根节点 `CharacterRoot` 在世界原点。

| 节点 | 控制方式 |
|---|---|
| `Face` | `FaceWidth` morph target，权重 0 为基础、1 为宽度增加 22%；建议权重限幅 |
| `EyeL` / `EyeR` | 空父节点，移动 X 调眼距、缩放 X 调眼长、缩放 Y 调眼高、旋转 Z 调眼倾斜 |
| `BrowL` / `BrowR` | 空父节点，Y 位置调眉高，子网格含眉形 |
| `Nose` | 父节点缩放 X 调鼻宽 |
| `Mouth` | 父节点缩放 X 调嘴宽 |
| `Head` | 全头父节点，可作轻微转头 |
| `ArmL/R` / `LegL/R` | 技术分组，枢轴仍在原点，不是可生产的骨骼绑定 |
| `OutfitSkirt` | `OutfitSage` 材质，裙子染色 |
| `OutfitBodice` 与袖子 | `OutfitIvory` 共享材质，上衣染色 |

眼睛、眉毛、鼻、嘴是具有子网格的父节点，不能只改单独眼白。左眼初始坐标 (-0.039, 1.615, 0.073)，右眼为 X=+0.039，眉高 1.645，嘴高 1.55，鼻高 1.585。全部修改应基于加载时的初始值，避免累积误差。

面宽目前仅修改面部网格，眼睛和眉毛位置需要渲染器联动或限制极端值。移动鼻嘴过大可能离开皮肤表面。当前支持的是小范围技术验证，不是承诺支持 100 项完善捏脸。
